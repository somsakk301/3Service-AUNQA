ถ้าตารางมีคอลัมน์ชื่อ "ตำแหน่งทางวิชาการ" คู่กับ "ชื่อ-นามสกุล" (หรือความหมายเดียวกัน) ต้องแยกข้อมูลตามกฎนี้เป๊ะๆ:
  * คอลัมน์ "ตำแหน่งทางวิชาการ" ใส่เฉพาะตำแหน่งทางวิชาการล้วนๆ เท่านั้น ("ศาสตราจารย์", "รองศาสตราจารย์", "ผู้ช่วยศาสตราจารย์", "อาจารย์") ห้ามมีคำว่า "ดร." หรือส่วนใดของชื่อบุคคลปนอยู่ในคอลัมน์นี้เด็ดขาด
  * คอลัมน์ "ชื่อ-นามสกุล" ใส่ชื่อเต็มของบุคคล ถ้าบุคคลนั้นมีคำว่า "ดร." ให้ใส่ "ดร." ต่อหน้าชื่อจริงแบบไม่เว้นวรรค (เช่น "ดร.พีรวิชญ์ เควด") ถ้าไม่มี "ดร." ให้ใส่ชื่อ-นามสกุลตามจริงโดยไม่ตัดคำใดออก (เช่น "เจริญพร บัวแย้ม" ต้องมีทั้งชื่อและนามสกุลครบ ห้ามหลุดคำแรกของชื่อไปปนกับคอลัมน์ตำแหน่ง)

ถ้าตารางมีคอลัมน์ชื่อ "ชื่อปริญญา (สาขาวิชา)" หรือ "วุฒิการศึกษา" (หรือความหมายเดียวกัน) ให้ใส่ชื่อปริญญาเป็น "ชื่อย่อมาตรฐาน" ที่ใช้กันทั่วไปในสถาบันอุดมศึกษาไทย ไม่ใช่ชื่อเต็ม เช่น "ปรัชญาดุษฎีบัณฑิต" → "ปร.ด.", "วิทยาศาสตรมหาบัณฑิต" → "วท.ม.", "วิทยาศาสตรบัณฑิต" → "วท.บ.", "ครุศาสตรมหาบัณฑิต" → "ค.ม." (แปลงตามหลักชื่อย่อปริญญาไทยมาตรฐานทั่วไป ไม่ใช่แค่ตัวอย่างที่ยกมา) ถ้า Evidence ระบุปริญญาต่างประเทศเป็นภาษาอังกฤษอยู่แล้ว (เช่น "Ph.D.", "M.Sc.", "B.Eng.") ให้คงรูปแบบย่อสากลนั้นไว้ตามเดิม ห้ามใช้ชื่อเต็มถ้ามีชื่อย่อมาตรฐานอยู่แล้ว
